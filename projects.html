Android Mobile Application

MyBP บันทึกสุขภาพความดัน

ที่มาของผลงาน : โปรเจกต์นี้มีจุดเริ่มต้นมาจากแม่ของผมมีภาวะความดันโลหิตไม่คงที่ แพทย์ได้แนะนำให้จดบันทึกค่าความดันอย่างสม่ำเสมอ แต่ที่ผ่านมามักพบปัญหาลืมจดบันทึกหรือทำเอกสารสูญหาย ส่งผลให้แพทย์ขาดข้อมูลต่อเนื่องในการติดตามอาการ ผมจึงนำความรู้ทางเทคโนโลยีช่วยแก้ปัญหานี้ ด้วยการพัฒนาแอปพลิเคชันบนสมาร์ตโฟน เพื่อให้การบันทึกข้อมูลเป็นเรื่องง่าย

แนวคิด : การพัฒนาแอปพลิเคชันสำหรับบันทึกข้อมูลและจัดการข้อมูลสุขภาพส่วนบุคคล แทนการจดบันทึกบนกระดาษ พร้อมระบบประมวลผลและแจ้งเตือนอัตโนมัติที่ใช้งานง่าย

วัตถุประสงค์
  1. เพื่อพัฒนาแอปพลิเคชันบันทึก ติดตาม และประมวลผลค่าความดันโลหิตเบื้องต้น
  2. เพื่อสร้างระบบแจ้งเตือนนัดหมายแพทย์แบบเรียลไทม์
  3. เพื่อให้มีฐานข้อมูลสุขภาพส่วนบุคคล พร้อมนำไปประเมินแนวทางการรักษาร่วมกับแพทย์ได้ทันที
วิธีการดำเนินงาน
  • การพัฒนา : การเตรียมระบบและกำหนดโครงสร้าง Folder Project ใน Visual Studio Code จากนั้นออกแบบ UI และเขียนโค้ดพัฒนาระบบต่าง ๆ ด้วย Flutter Framework (ภาษา Dart)
  • การทดสอบระบบ : รันและทดสอบการทำงานเครื่องจำลอง (Emulator) ใน Android Studio และเชื่อมต่อเครื่องจริง ผ่านสาย USB เพื่อตรวจสอบการแสดงผล และประสิทธิภาพการทำงานของระบบ
  • การแก้ปัญหา : ตรวจสอบการทำงานของโค้ดผ่าน Debug Console และดำเนินการแก้ไข Error ต่าง ๆ จนมั่นใจว่าแอปพลิเคชันสามารถทำงานได้อย่างถูกต้อง และเสถียรตามที่ได้ออกแบบไว้
