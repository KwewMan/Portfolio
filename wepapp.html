Web Application "ระบบบันทึกข้อมูลอุปกรณ์"

การพัฒนาเว็บแอปพลิเคชันระบบบันทึกข้อมูลอุปกรณ์ ด้วย Canva AI, Google Sheets และ Google Apps Script โดยแบ่งการทำงานเป็น 2 ส่วนอย่างเป็นระบบ ประกอบด้วย

Link 1 : ระบบบันทึกข้อมูล สำหรับพนักงาน

Link 2 : ระบบของผู้บริหาร

กระบวนการพัฒนาเริ่มต้นจากการใช้คำสั่ง (Prompt) ร่วมกับ Canva AI ในการออกแบบหน้าจอ จากนั้นนำโค้ดไปปรับแต่งบน Visual Studio Code เพื่อเชื่อมข้อมูลผ่าน Google Apps Script โดยข้อมูลจากฟอร์มจะถูกส่งไปยังฐานข้อมูล Google Sheets

ระบบจะดึงข้อมูลจากตารางกลับมาอัปเดตบนหน้า Dashboard แบบเรียลไทม์ผ่านการเปิดใช้งาน เว็บแอปพลิเคชันทั้ง 2 ส่วน

ผลลัพธ์ที่ได้ช่วยให้พนักงานสามารถบันทึกข้อมูล ได้สะดวกผ่านสมาร์ตโฟนหรือคอมพิวเตอร์ และผู้บริหารสามารถตรวจสอบสถานะอุปกรณ์ ได้ทันที ช่วยลดขั้นตอนและเพิ่มประสิทธิภาพ ในการบริหารจัดการได้อย่างเป็นรูปธรรม

ลิงก์ฟอร์มบันทึกข้อมูลอุปกรณ์ ลิงก์ Dashboard สรุปผล

สิ่งที่ได้เรียนรู้ : ได้พัฒนาทักษะด้าน Prompt Engineering ในการสั่งงาน AI ควบคู่กับการออกแบบ UI ของระบบเว็บแอปพลิเคชัน ตลอดจนทักษะ การแก้ไขโค้ดผ่านโปรแกรม Visual Studio Code เพื่อเชื่อมต่อระบบได้อย่างถูกต้อง
